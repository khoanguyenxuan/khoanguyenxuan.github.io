Hi, I'm Khoa Nguyen Xuan. I'm a security researcher whose main obsession is
**fuzzing for bugs** — throwing malformed, mutated, and unexpected input at
software until it breaks in interesting ways.

This blog is where I write about fuzzing campaigns, harness design, crash
triage, and the tools I use every day:

- **Coverage-guided fuzzers**: AFL++, libFuzzer, Honggfuzz
- **Instrumentation**: Sanitizers (ASan, UBSan, MSan), QEMU, Frida
- **Targets**: parsers, file formats, network protocols, and anything in C/C++

You can find my projects and code on [GitHub](https://github.com/khoanguyenxuan).
