This site is a static blog built with [Jekyll](https://jekyllrb.com/) and the
[Minima](https://github.com/jekyll/minima) theme, deployed through
[GitHub Pages](https://pages.github.com/).

The workflow is simple:

1. Write a Markdown file in the `_posts` folder named
   `YYYY-MM-DD-title.md`.
2. Add front matter with a `title`, `date`, and `layout: post`.
3. Commit and push to the `main` branch.
4. GitHub Pages rebuilds and publishes the site automatically.

No database, no servers — just Markdown files in a git repository.
